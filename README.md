# Letta Web Platform

**Eine Web-basierte Multi-Agent AI Plattform** - Besser als Happy Coder!

## 🚀 Features

### Core Features
✅ **Multi-Agent System** - 9 spezialisierte AI Agents  
✅ **Smart Agent Selection** - Automatische Auswahl des besten Agents für deine Anfrage  
✅ **Model-Agnostic** - Claude, GPT-4, Gemini, lokale Models  
✅ **Persistent Memory** - Agents lernen über Zeit  
✅ **Real-time Communication** - WebSocket für Live-Updates  
✅ **Modern Web UI** - Next.js + React + TailwindCSS

### Advanced Features  
✨ **Agent Collaboration** - Mehrere Agents arbeiten zusammen  
✨ **Auto-Select Mode** - AI wählt den besten Agent basierend auf deiner Frage  
✨ **Manual Mode** - Du wählst den Agent selbst  
✨ **Conversation Memory** - Agents erinnern sich an frühere Gespräche  
✨ **Production-Ready** - Vollständig optimierte Agent-Profile

---

## 🛠️ Quick Start

### 1. Backend starten
```bash
cd backend
npm install
# Füge deinen LETTA_API_KEY in .env ein
npm run dev
```
Backend: http://localhost:3001

### 2. Frontend starten
```bash
cd frontend
npm install
npm run dev
```
Frontend: http://localhost:3000
